# #055 Backlog: self-host relay dengan satu perintah

**Backlog: Pembeda tambahan** · Ukuran M · Bergantung pada: [#047](047-rilis-beta-publik.md)

## Tujuan
Memungkinkan pengguna menjalankan relay sendiri dengan satu perintah.

## Tahapan
1. Kemas relay dan database supaya bisa dijalankan bersama.
2. Otomatiskan pembuatan kunci yang dibutuhkan.
3. Tambahkan pilihan alamat relay saat setup.
4. Tulis panduan, termasuk HTTPS.

## Selesai bila
- [ ] Relay berjalan dengan satu perintah di server bersih.
- [ ] Pairing dan push berfungsi lewat relay sendiri.
