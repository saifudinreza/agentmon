# #051 Extension editor

**Tahap 8: Extension** · Ukuran M · Bergantung pada: [#047](047-rilis-beta-publik.md)

## Tujuan
Menyediakan instalasi tanpa terminal melalui extension editor.

## Tahapan
1. Buat paket extension.
2. Pakai ulang logika setup yang sama dengan CLI.
3. Tambahkan tombol "Pair device" yang menampilkan QR.
4. Tampilkan status daemon dan relay di status bar.

## Selesai bila
- [ ] Setup sampai pairing berhasil tanpa membuka terminal.
- [ ] Bila Node.js belum terpasang, ada panduan yang jelas.
- [ ] Startup editor tidak terasa lebih lambat.

**Rujukan:** FR-60.
