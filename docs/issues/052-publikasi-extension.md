# #052 Publikasi extension ke Marketplace dan Open VSX

**Tahap 8: Extension** · Ukuran S · Bergantung pada: [#051](051-extension-editor.md)

## Tujuan
Menyediakan extension di marketplace yang dipakai tiap editor.

## Tahapan
1. Siapkan publisher di VS Code Marketplace dan Open VSX.
2. Otomatiskan publikasi lewat CI.
3. Uji di VS Code, Antigravity, Cursor, dan Windsurf.

## Selesai bila
- [ ] Extension bisa di-install dari kedua marketplace.
- [ ] Hasil uji per editor tercatat, termasuk keterbatasannya.
